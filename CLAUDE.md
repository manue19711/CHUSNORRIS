# CHUSNORRIS

## Diseño web

Cuando se pida diseñar, crear, rediseñar o pulir una página web, landing, sitio, portfolio, dashboard o
pantalla web, invoca **primero** la skill `disenar-web` y sigue sus fases. Esa skill encadena todas las
skills de diseño del proyecto (`impeccable`, `design-taste-frontend`, `frontend-design`, `emil-design-eng`,
estilos, animación, móvil y revisión) para que trabajen juntas.

## Motxilla 2A (app infantil)

Si el trabajo es sobre la app de Motxilla 2A (`motxilla-2a-nou/`), lee primero `motxilla-2a-nou/RESUM.md`: tiene el mapa de ficheros, cómo generar el zip, lo pendiente y las decisiones ya tomadas. No edites `motxilla-2a/` (es la versión original). Cada cambio en `motxilla-2a-nou/` requiere subir la versión de `sw.js`, regenerar `Motxilla-2A-nou-disseny.zip` y hacer commit y push.
