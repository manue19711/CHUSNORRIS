# CHUSNORRIS

## Diseño web

Cuando se pida diseñar, crear, rediseñar o pulir una página web, landing, sitio, portfolio, dashboard o
pantalla web, invoca **primero** la skill `disenar-web` y sigue sus fases. Esa skill encadena todas las
skills de diseño del proyecto (`impeccable`, `design-taste-frontend`, `frontend-design`, `emil-design-eng`,
estilos, animación, móvil y revisión) para que trabajen juntas.
